# ShilajitDB — Claude Context

## What this is
Transparency database for shilajit supplements. Editorial tone. Rates products on COA quality, lab credibility, heavy metals safety, manufacturing transparency.

## Stack
Next.js 15 App Router · TypeScript · Prisma 6 + PostgreSQL (Supabase) · Tailwind CSS · Vercel

## Architecture
- `app/` — all routes (no Pages Router)
- `app/learn/[slug]/` — 35 static editorial articles; `lib/learn-articles.ts` (`LEARN_ARTICLES`) is the single registry — the /learn index, sitemap, `/llms.txt` and homepage "last updated" stat all read it (replaced the hand-kept lists in `app/learn/page.tsx`, `app/sitemap.ts` `LEARN_SLUGS` and `lib/article-dates.ts`, which had drifted)
- `app/llms.txt/route.ts` — `/llms.txt`, generated hourly from the live DB (A+/A products with ≥2 evidence), `overallRubric`/`FORM_GRADE_CEILING` and `LEARN_ARTICLES`; its `BEST_PAGES` list is hand-kept like `BEST_TAGS` in the sitemap
- `app/best/[tag]/` — 10 ranking pages, driven by `bestForTags` field
- `app/product/[slug]/` + `/lab-results` — per-product pages
- `app/brand/[slug]/` + `/lab-tests` — per-brand pages
- `app/compare/[pair]/` — compare pages (15-product compare set = 105 pairs; set comes from `getCompareProducts()` in `lib/compare-set.ts` — top-graded, max 2 per brand, Life Cykel counts as Pürblack; used by `generateStaticParams`, related-pair links, product-page quick-compare links and the sitemap)
- `components/product-card.tsx` — shared card used everywhere
- `lib/db.ts` — Prisma singleton
- `prisma/schema.prisma` — source of truth for all enums

## Key enums (don't re-ask)
- `OverallGrade`: A_PLUS, A, B, C, D, E, F (no B_PLUS)
- `QualityTier`: ULTRA_PREMIUM, PREMIUM, AVERAGE, POOR
- `CoaStatus`: PUBLIC, PUBLIC_EMBEDDED, REQUEST_ONLY, NONE, UNKNOWN
- `HeavyMetalsTested`: CONFIRMED (numeric ppm on public COA), CLAIMED, NONE
- `bestForTags`: String[] — drives all /best/[tag] pages, 2-per-brand cap, 15 max per tag. Generated by `scripts/retag-best-for.ts` (dry run by default, `--apply` to write) — per-tag eligibility rules, `BRAND_GROUPS` (Life Cykel counts as Pürblack), `PREFERRED` (White Rabbit Slim fills Pürblack's slot on best_for_women, disclosed in page copy). `editors_pick` is hand-curated in `scripts/set-editors-picks.ts` and never touched by the retag script. Re-run it after any grade change.

## DB access
As of Sep 2026, local scripts reach Supabase fine: run them with `./node_modules/.bin/tsx scripts/<name>.ts` (read-only temp scripts go in `scripts/tmp-*.ts` and get deleted after — `@prisma/client` doesn't resolve from the scratchpad). The pooler (`DATABASE_URL`, port 6543) works for queries but `prisma migrate` commands hang on it; point them at the direct connection instead: `DATABASE_URL="$(grep '^DIRECT_URL=' .env | cut -d= -f2- | tr -d '"')" ./node_modules/.bin/prisma migrate status`. Writes to the live DB may be blocked by the auto-mode classifier unless the script has an allow rule in `.claude/settings.local.json`. (Older fallback, from when local access was IP-blocked: one-shot admin API routes deployed to Vercel, called from the browser console, then deleted.)

## Conventions
- All DB queries filter `isCanonical: true, dataCompleteness: { not: "LOW" }`
- Dark theme throughout: bg `#0F1320`, text `#EEF0F8`, muted `#8892B8`, subtle `#4A5070`
- No product images — grade badge is the visual anchor
- Ranking pages read only from `bestForTags`; never hardcode product queries per tag
- Learn articles: ArticleSchema component, breadcrumb, category badge, h1, "Last reviewed", browse link, CTA block with /best/[tag] links, 2 related articles
- New learn article: add ONE entry to `LEARN_ARTICLES` in `lib/learn-articles.ts` (slug, title, description, tag, published, updated) — that's the only registration step now (older entries below mentioning "all three places" / `LEARN_SLUGS` / `lib/article-dates.ts` are superseded). Link to it from at least one existing article so it isn't a crawl orphan. After committing edits to any article, run `./node_modules/.bin/tsx scripts/sync-learn-updated.ts` so the sitemap `lastModified` stays accurate
- Admin pages: every `app/admin/(protected)/**/page.tsx` must call `await requireAdmin()` (`lib/admin-auth.ts`) first — the layout's check runs in parallel and does not stop the page's data reaching logged-out requests. Server actions and `/api/admin/*` routes check `isAdminAuthed()` themselves
- Admin CSV export/import (`app/admin/(protected)/data/`): export header list and row values must stay the same length (the importer parses strictly and rejects mismatched rows). Bulk import runs only off Vercel (`IMPORT_ENABLED = !process.env.VERCEL`)
- Indexing rules (keep page robots tag and sitemap in sync): products noindexed below 2 evidence sources; brands noindexed when no product is indexable (`lib/brand-indexing.ts`); `/brand/[slug]/lab-tests` has no noindex rule (deliberate, 2026-09-16)

## Rendering strategy (don't re-litigate)
